# Furnace Controller PCB

Hardware revisions are kept side by side:

- `Furnace_Controller_V1/` — the original 99-footprint design, last produced in June 2026.
- `Furnace_Controller_V2/` — the active 125-footprint revision, including the expanded functional-sheet hierarchy and TI footprint corrections.

Open the `Furnace_Controller.kicad_pro` inside the revision you intend to edit.
Shared third-party symbols and footprints live in `libraries/Symbols/`; each revision's
library-table files resolve these assets using project-relative paths.
